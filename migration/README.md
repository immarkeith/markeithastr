# ASTR — self-hosting database setup

**Use `fresh/` for a new setup.** `fresh/README.md` has the exact step-by-step
instructions and 9 phone-sized SQL files exported straight from the live
database, so the new project matches this app exactly (structure, permissions,
strategies, researchers, Master Formula rules, settings, and the automatic
daily schedule).

`astr-full-schema.sql` is the older hand-merged migration history. It is kept
for reference only and is missing later tables and columns — do not use it for
a new setup.
