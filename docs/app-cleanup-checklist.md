# ASTR Cleanup Checklist

Replace the `[ ]` in front of each line with one letter:

- **K** = Keep (stays visible, works as today)
- **M** = Move to background (keeps running and saving data, but hidden from the screen)
- **D** = Delete (removed from the app)

Example: `[M] H2 — Market status bar`

Leave a line as `[ ]` if you are unsure — it will be left alone. Add notes after any line with `—note:`.
